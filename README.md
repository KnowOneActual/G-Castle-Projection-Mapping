# G-Castle Projection Mapping

A professional, repeatable projection mapping project for holiday events (Christmas, Halloween, etc.) at the G-Castle (A good friend's house) :). This project focuses on high-impact visuals using budget-friendly, open-source, or consumer-grade tools.

## 🏰 Project Vision
Transform the G-Castle into a dynamic, immersive experience using 3D projection mapping that can be easily deployed and repeated each season.

## 📂 Project Structure
- `01_Research/`: Hardware specs, software reviews, and case studies.
- `02_Planning/`: Deployment plans, site maps, and calibration guides.
- `03_Assets/`: Projection masks, custom media, and sourced animations.

## 🛠️ Current Tech Stack
- **Mapping Software:** [Digital Pressworks Free Mapper](https://digitalpressworks.com/free-mapping-software/)
- **Compositing & Editing:** DaVinci Resolve
- **Playback Hardware:** Micca Player (or similar standalone media player). Possibly a Raspberry Pi.
- **Projector:** (TBD - See Research)

## 📅 Roadmap (2026 Revision)
1. **Site Mapping:** Create precise masks for the castle's geometry.
2. **Content Strategy:** Source and create holiday-specific animations.
3. **Hardware Deployment:** Finalize projector placement and weatherproofing.
4. **Playback Automation:** Set up loops and timing for the event.
